# POLLEN

**Test Ideas. Understand People. Create Better Campaigns.**

POLLEN connects brands with real people to test ads, posters, videos and campaign ideas before launch. This repo holds the interactive demo prototype.

- Live site: https://ezhilgopal2005-gif.github.io/pollen.com-/
- Demo logins: `brand@pollen.com` / `demo123` and `user@pollen.com` / `demo123`

The whole site is a single `index.html` file, with React and icons loaded from a CDN.
